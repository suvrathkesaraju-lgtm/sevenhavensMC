# ash
A Mod for Minecraft created to bring Avatar  Seven Havens Inspired Blocks and More

## Changes to the game so far

-Added 4 Blocks
  - Air Block
  - Anomaly BLock
  - Anomaly Remnant
  - Air Remnant
- Added 2 Items
  - Anomaly Shards
  - Air Shards
- Added  4 Crafting recipes
  - 9 Air Shards ->  Block of The Air Spirit
  - 9 Anomaly SHard -> Block from the Anomaly
  - 1 Block of Air Spirit -> 9 Air Shards
  - 1 Block from the Anomaly ->9 Anomaly shards
 - Added a Creative Mode tab for the game
 - Added Loot Tables
  - Air Remnant drops Air shard
  - Anomaly Remnant drops Anomaly shard
  - Everything Else drops itself
